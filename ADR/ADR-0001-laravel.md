# ADR-0001: Laravel 13 as Core Framework

**Status**: Accepted

**Context**
Need rapid SaaS development with built-in Auth, Queues, Multi-tenancy, and AI integration.

**Decision**
Use Laravel 13 with Octane and Reverb.

**Consequences**
+ Faster development and vast ecosystem.
+ First-party AI capabilities.
- Slightly more memory usage compared to bare FastAPI.
